UTeM SOC Phishing Detection System

Intelligent Management Framework for Mitigating Social-Engineered Spam and Cyber Threats in University Social Groups

Real-time WhatsApp Monitoring with Machine Learning

Problem Statement
  • University WhatsApp groups are high-trust environments vulnerable to phishing attacks
  • Manual moderation is limited - administrators may not be online when threats appear
  • Existing commercial filters focus on standard English, not Malaysian multilingual communication
  • Students may click malicious links before warnings are posted
  • Need for real-time, automated detection and response system
Project Objectives
  • Develop real-time WhatsApp group monitoring system
  • Implement ML-based phishing detection for Manglish (Malaysian English)
  • Create automated warning system for high-risk threats
  • Build interactive dashboard for system monitoring
  • Achieve high accuracy with low false positive rate

Preprocessing Pipeline
  • Text Normalization: Lowercasing, special character stripping
  • Manglish Normalization: "u" → "you", "pls" → "please", "blh" → "boleh"
  • Stop-word Removal: Bilingual English-Malay stop-word dictionary
  • Tokenization: Split text into tokens
  • TF-IDF Vectorization: Convert text to numerical vectors

ML Engine: Scoring Function

Core scoring algorithm (learning_engine.py):

learning_engine.py - score_text()
def score_text(text: str, bundle: dict[str, object]) -> dict[str, object]:
    feature_signals = extract_feature_signals(text)
    vector = _vectorize_messages(bundle["vectorizer"], [text])
    dense = csr_matrix([[feature_signals[name] for name in FEATURE_COLUMNS]])
    combined = hstack([vector, dense], format="csr")
    rf_score = float(bundle["rf_model"].predict_proba(combined)[0][1])
    svm_score = float(bundle["svm_model"].predict_proba(combined)[0][1])
    base_score = (rf_score + svm_score) / 2
    return {
        "risk_score": _calibrate_risk_score(base_score, feature_signals),
        "rf_score": rf_score,
        "svm_score": svm_score,
        "feature_signals": feature_signals,
        "model_version": bundle["metrics"]["model_version"],
    }

Process: Extract features → Vectorize → RF + SVM scoring → Average → Calibrate → Return risk score

WhatsApp Monitoring Loop

Real-time message processing (radar.py):

radar.py - whatsapp_monitor_worker()
while should_continue():
    try:
        recent_messages = _get_recent_message_texts(driver)
        
        for latest_message in recent_messages:
            if not latest_message.strip() or "[UTeM SOC Bot" in latest_message:
                continue
            
            if latest_message in seen_messages:
                continue
            
            seen_messages.append(latest_message)
            
            average_score = float(score_text(latest_message, model_bundle)["risk_score"])
            
            on_message({
                "text": latest_message,
                "type": "chat",
                "risk": float(average_score),
            })
            
            if average_score >= AUTO_WARNING_THRESHOLD:
                _send_warning(driver, average_score, on_message)
                
    except Exception as loop_exc:
        err_str = str(loop_exc)
        if "no such window" in err_str or "chrome not reachable" in err_str:
            break
        time.sleep(2)
    
    time.sleep(2.0)

Flow: Poll messages → Deduplicate → Score → Broadcast → Auto-warn if risk ≥ 90%

Risk Calibration Rules

Rule-based post-processing adjustments:

  • Increase risk: Shortlink + action phrase (+0.08)
  • Increase risk: Brand domain mismatch (+0.10)
  • Increase risk: Chinese action phrase (+0.05)
  • Increase risk: Chinese URL (+0.08)
  • Decrease risk: Trusted domain + brand match (-0.12)
  • Decrease risk: Trusted domain + event context (-0.12)
  • Decrease risk: University context without shortlinks (-0.15)
  • Final score clamped to [0.01, 0.99]
Backend & API Design

FastAPI endpoint example (main.py):

main.py - POST /api/messages/analyze
@app.post("/api/messages/analyze")
async def analyze_message(payload: ManualAnalyzeRequest) -> JSONResponse:
    model_bundle = setup_security_models()
    risk_score = float(score_text(payload.text, model_bundle)["risk_score"])
    analysis_message = {
        "text": payload.text,
        "type": "manual-analysis",
        "risk": risk_score,
    }
    publish_message(analysis_message)
    return JSONResponse({"ok": True, "message": analysis_message})

Endpoints: analyze, review, start/stop monitor, status, WebSocket feed
